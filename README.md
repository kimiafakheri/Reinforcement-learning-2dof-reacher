# Reinforcement Learning for 2-DOF Robotic Reaching

## Overview
This project investigates classical control and reinforcement learning approaches for controlling a two-link robotic arm to reach static and moving targets.

## Implemented Methods
- PID controller (task-space control)
- PID with inverse kinematics
- N-step SARSA
- Deep Deterministic Policy Gradient (DDPG)

## Environment
- Python
- Gymnasium-style custom environment
- Torque-based control

## Experiments
- Exploration analysis
- Generalization to different targets
- Ablation studies
